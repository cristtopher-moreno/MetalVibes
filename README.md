# 🤘 Metal Vibes - Regalos de Metal Puro

![Metal Vibes Banner](https://images.unsplash.com/photo-1511735111819-9a3f7709049c?q=80&w=1200&auto=format&fit=crop)

**Metal Vibes** es una landing page de alto impacto diseñada para una tienda exclusiva de accesorios, reliquias y decoración inspirada en la cultura del heavy metal. El proyecto combina una estética brutalista y oscura con una experiencia de usuario moderna y fluida.

## 🛠️ Tecnologías Utilizadas

El desarrollo se fundamenta en un stack moderno para garantizar rendimiento y escalabilidad:

- **HTML5:** Estructura semántica avanzada.
- **CSS3 (Tailwind CSS):** Estilizado mediante utilidades y diseño responsivo "Mobile-First".
- **JS ES6+ (React 19):** Lógica de componentes y manejo de estado.
- **Motion:** Animaciones premium y transiciones fluidas.
- **Firebase (Firestore & Auth):** Persistencia de leads y autenticación anónima.
- **Lucide React:** Set de iconos minimalistas.
- **Google AI Studio / Gemini:** Utilizado para la generación de contenido, optimización de copies y asistencia en el desarrollo del código.

## 📈 Proceso de Desarrollo (Metodología de 5 Fases)

Este proyecto fue ejecutado siguiendo una metodología rigurosa para asegurar la calidad del producto final:

1.  **Fase 1: Investigación y Conceptualización:** Definición del buyer persona (metaleros, músicos, entusiastas de la cultura alternativa) y selección de la paleta de colores "Metal Black & Accent Lavender".
2.  **Fase 2: Arquitectura y Wireframing:** Diseño de la jerarquía visual priorizando el CTA (Call to Action) "Únete a la horda" y la sección de captura de leads.
3.  **Fase 3: Diseño UI y Estilizado:** Implementación del tema visual en Tailwind CSS, integrando tipografías de alto impacto como *Anton* para títulos y *JetBrains Mono* para detalles técnicos.
4.  **Fase 4: Desarrollo Frontend e Integración:** Programación de componentes en React y conexión con Firebase Firestore para el almacenamiento de registros en tiempo real.
5.  **Fase 5: Optimización y Lanzamiento:** Pruebas de usabilidad, optimización de activos y despliegue en la infraestructura de Cloud Run.

## ⚙️ Instrucciones de Personalización

Si deseas adaptar este proyecto para tu propia marca, sigue estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/tu-usuario/metal-vibes.git
    ```
2.  **Configurar variables de entorno:**
    Crea un archivo `.env` basado en `.env.example` y añade tus credenciales de Firebase.
3.  **Cambiar Identidad Visual:**
    Modifica el archivo `src/index.css` en la sección `@theme` para cambiar los colores `--color-metal-accent` y las fuentes.
4.  **Actualizar Catálogo:**
    Edita las secciones de productos y testimonios en `src/App.tsx`.
